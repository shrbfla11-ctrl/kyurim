# PUF 메인페이지 디자인 프롬프트 (Claude Design 용)

아래 내용을 Claude Design 프롬프트창에 그대로 붙여 넣어 사용합니다.

---

## 프로젝트
"PUF (Physical Unclonable Function)" — 알약을 스마트폰 카메라로 비추면 알약 표면에 각인/코팅된 식별 문자를 인식해 그 알약의 성분·효능·주의사항을 알려주는 웹 서비스.
이번 작업은 **메인(랜딩) 페이지 1장**, 모바일 우선(390px) + 데스크톱(1440px) 두 아트보드.

## 디자인 방향
- 토스(Toss) 앱의 디자인 언어를 따를 것: 넉넉한 여백, 큼직하고 단순한 타이포, 카드 기반 레이아웃, 한 화면에 하나의 메시지, 장식 최소화, 둥근 모서리(16–24px), 은은한 그림자.
- 컬러: 화이트/블루 컨셉. 배경 #FFFFFF, 보조 배경 #F2F4F6, 포인트 블루 #3182F6, 진한 텍스트 #191F28, 보조 텍스트 #6B7684, 성공 그린(인식 완료용) 소량.
- 최신 트렌드 반영: Pinterest 에서 "2025 fintech app UI", "toss app design", "medical app minimal UI", "camera scan UI", "bento grid landing" 로 검색되는 레퍼런스 톤(벤토 그리드, 큼직한 히어로, 부드러운 그라데이션 블루, 3D 아이콘 소량, 마이크로 인터랙션 느낌의 상태 표시)을 참고할 것. 단, 화려함보다 신뢰감과 명료함을 우선.
- 폰트: Pretendard(없으면 Inter/Noto Sans KR). 제목 28–40px Bold, 본문 15–17px Regular, 행간 1.5.
- 톤: 의료 정보 서비스이므로 신뢰감·안전함이 느껴져야 하며, 병원처럼 차갑지 않고 토스처럼 친근해야 함.

## 페이지 구성 (위에서 아래 순서)
1. **상단 내비게이션**: 로고(PUF 블루 워드마크, 작은 서브텍스트 "Physical Unclonable Function"), 메뉴 3개(알약 검색, 복용 기록, 안내), 우측 "시작하기" 블루 버튼. 모바일은 햄버거.
2. **히어로**: 한 줄 헤드라인 "알약, 카메라에 비추면 바로 알 수 있어요" + 서브카피 한 문장. 주요 CTA "카메라로 알약 인식하기"(블루, 크고 둥근 버튼) + 보조 CTA "각인 문자로 검색". 우측(모바일은 아래)에 스마트폰 화면 목업: 카메라 뷰파인더 안에 알약이 있고, 각인 문자가 하이라이트되며 인식 결과 카드가 떠 있는 장면.
3. **인식 방법 3단계** (가로 3 카드, 모바일은 세로): ① 카메라로 알약 비추기 → ② 각인·색·모양 자동 인식 → ③ 성분·효능·주의사항 확인. 각 카드에 단순한 라인/3D 아이콘, 짧은 제목, 한 줄 설명.
4. **결과 미리보기 카드**: 실제 인식 결과가 어떻게 보이는지 보여주는 큰 카드 1개. 알약 이미지, 약 이름, 주성분, 효능 태그 2–3개, "복용 시 주의" 경고 박스(옅은 옐로/레드 배경), "신뢰도 98%" 같은 인식 신뢰도 배지.
5. **주요 기능 벤토 그리드** (4–5 블록): 각인 문자 검색 / 색·모양으로 찾기 / 복용 기록 저장 / 함께 먹으면 안 되는 약 알림 / 가족 약 관리. 블록 크기를 달리해 리듬감.
6. **신뢰 섹션**: "식품의약품안전처 공공데이터 기반" 문구, 등록 알약 수·인식 정확도·사용자 수 등 숫자 3개(플레이스홀더).
7. **FAQ 3개** (아코디언): 인식이 안 되는 경우, 개인정보(사진 저장 여부), 의료 조언 대체 불가 안내.
8. **하단 CTA 배너 + 푸터**: 블루 배경 배너 "지금 바로 알약을 확인해 보세요" + 버튼. 푸터에 서비스명, 이용약관, 개인정보처리방침, 면책 문구("본 서비스는 참고용이며 의사·약사의 진단을 대체하지 않습니다").

## 컴포넌트 규칙
- 버튼: 높이 52–56px, 라운드 14–16px, 기본 블루 채움 / 보조 옅은 블루 배경(#E8F3FF)에 블루 글자.
- 카드: 화이트 배경, 라운드 20px, 그림자 0 2px 12px rgba(0,0,0,0.06), 내부 패딩 24px.
- 아이콘: 라인 아이콘 2px 두께 또는 부드러운 3D 아이콘, 블루 계열 단색.
- 카메라 UI 목업: 뷰파인더 모서리 가이드 4개, 인식 중 스캔 라인, 인식 완료 시 그린 체크와 결과 카드 슬라이드업.

## 산출물
- 모바일(390×자유 높이), 데스크톱(1440×자유 높이) 아트보드 각 1개.
- 카피는 모두 한국어. 실제 약 이름은 예시("타이레놀정 500mg, 아세트아미노펜")로 채우고, 숫자는 플레이스홀더로 표기.
- 각 섹션은 Tailwind 로 구현하기 쉬운 8px 그리드 기준으로 정렬.
